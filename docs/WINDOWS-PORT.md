# Windows port: change log

Every Windows change on the `windows-port` branch gets one row here. Rules are in [CLAUDE.md](../CLAUDE.md), the plan and status in [PHASE1-PLAN.md](PHASE1-PLAN.md).
Install steps for a new Windows PC: [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md).

## Summary (Phase 1, 2026-11-07)

ghost-editor runs on native Windows 11 (Git Bash for the .sh scripts, no WSL). The macOS code path is unchanged: every
Windows change is a `sys.platform == "win32"` / `process.platform === "win32"` / `$OSTYPE` branch, or works the same on both.

- **Where the platform logic lives:** `scripts/plat.py` (Python), `scripts/lib/plat.mjs` (Node), `scripts/lib/plat.sh` (bash).
  Venv programs in `Scripts\`, npx without a shell, Git Bash (never WSL's), link fallbacks, file locks, ffmpeg filter
  paths, opening files, the caption OCR command, own-footage folders, CUDA DLLs.
- **New Windows-only pieces:** the HyperFrames ffmpeg launchers (`setup_hf_ffmpeg.py` -> `scripts\win-bin\*.exe`, from
  `hf_ffmpeg.py` / `hf_mix_pcm.py`), RapidOCR caption OCR (`ocr_text_rapid.py`, measured `CAP_RATIO_RAPID = 1.06`),
  CUDA in matte.py / cutout_fx.py, CUDA torch indexes in the setup scripts.
- **Opt-in, both platforms:** faster-whisper (`transcribe.py --backend faster`, `GHOST_ASR=faster`).
- **Upstream bugs fixed on the way** (same result on macOS): finals.py's fcntl import, prep.sh's GNU `tr` range and
  ffprobe CRLF, the trailing comma in Clean OS assemble.py's frame count, gen_luts.py's split paths.
- **Verified on Windows:** doctor.sh 26 ok / 0 missing; tests/ 3 of 3 pass; a clean-preset reel through approval, preview,
  render and qa (step 4: qa fails on creative budgets of that test reel, not on Windows issues); a Clean OS preview
  (step 8); every recipe builder starts; every optional tool runs (step 7).
- **Known limits on Windows** (PHASE1-PLAN.md, known issues): no Cyrillic caption OCR; NVENC needs a newer driver
  (recorded only, never used); `python -I` scripts need explicit UTF-8; scripts that rewrite tracked files write CRLF;
  insert_prep.py / house_look.py LUT paths and audition.py's `open` are not ported yet; transitions.py's zoom_blur window
  and seoul.py's `python -c` paths fail on Windows.
